How it was built
  1. 40,950 written reviews from the public Olist dataset, in Portuguese.
  2. Each one classified into 12 complaint themes by Qwen 2.5 7B, running locally through Ollama, with answers forced into a fixed JSON format.
  3. Theme definitions settled in a written labelling guide, and the same rules given to the model.
  4. Themes joined to orders, delivery dates, sellers and repeat purchases.

Code, decisions log and full report on GitHub. English translations of example reviews come from an offline translation model.
